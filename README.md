# Market Lab releases

Official prebuilt binaries for Market Lab CLI (`mlab`) and daemon (`mlabd`).
The core source code is private. This repository contains distribution files only.

[Download the latest release](https://github.com/emeraldls/marketlab-releases/releases/latest)

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/emeraldls/marketlab-releases/main/install.sh | bash
```

Existing installations that point to the former source repository need to run the installer once. Subsequent updates use `mlab upgrade`.

[Website](https://marketlab.sh) | [Documentation](https://docs.marketlab.sh)
